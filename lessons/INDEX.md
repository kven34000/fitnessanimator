# Уроки (ошибки, которые уже были, и правила)

## Анимация и спрайты
- [ноги] В нижних фазах ступни свисают за клетку листа → обувь обрезается. Брать человека с запасом под клеткой (`PMB=70 build_plate.py ...`), проверять ступни во всех фазах.
- [порядок фаз] Фазы из листа идут не всегда по порядку. Сортировать по высоте корпуса/углу, а не по номеру клетки.
- [темп] После медленной фазы цикл не должен «догонять» время — после паузы нормальный темп, длину цикла увеличить.
- [снаряды] Медианное голосование по кадрам ломает снаряд (дыры, лишние перекладины). Рабочий способ: правки `_noeq` (убрать снаряд) + `_plate` (только снаряд) → `build_plate.py`.
- [ракурс] Под 45° снаряд проходит перед телом и выглядит неправильно. Брусья — анфас, горизонтальные подтягивания — под столом сбоку.
- [сложная поза] Если модель упорно рисует позу неверно (горизонтальные подтягивания лицом вниз), собрать основу программно из удачного листа (перевёрнутые отжимания), загрузить и попросить «перерисовать чисто + добавить снаряд».
- [свечение] Вырез снаряда под ладонью даёт красный неоновый контур на кистях. Снаряд брать целым, с дорисованными рукоятками.
- [склейка] Один персонаж в соседних сценах на том же месте — без pop-выхода и pop-входа.

## Подсветка мышц и указатели
- [мышцы] Подсвечивать только мышцы, о которых речь (не ноги в сцене про спину). Каналы масок flex: 0 ноги, 2 пресс, 3 грудь.
- [кольца] Кольца и выделения ставить по реальному положению кисти/плеча на кадре, проверять стоп-кадром.

## Текст
- [облачка] Выноски — прямоугольник со скруглением ~26 px и просторными отступами; при появлении не выходить за край кадра.
- [плашки] Плашки не ставить поверх персонажа и друг на друга; при широких плашках раскладывать в две строки.
- [шрифт] Символов «≠», «→», «↓» нет в шрифте — переписывать текст.
- [субтитры] Перенос субтитров наверх (SUBDODGE) даёт мигание — выключен. Камера с зумом может толкнуть ноги в субтитры → CAM_FLOOR, CAM_MAXZ.

## Звук
- [вжухи] Одинаковые громкие вжухи раздражают. Варианты по высоте и громкости, ротация.

## Работа
- [кредиты] Всегда спрашивать точное число кредитов до платной генерации.
- [рендер] Pool(4) падает по памяти, только Pool(2). Склейка filter_complex на всём ролике тоже падает — частичный перерендер + concat.
- [Relax] При быстрой смене референса часть запусков теряется — ставить правки по одной с паузой ~8 с.

## Разбор референса
- [кадры] YouTube в встроенном браузере: viewport 1920x1100, `video.currentTime` шагом 2 с, canvas 6×6 с подписью времени, скриншот на лист (скриншот приходит 800 px, zoom не увеличивает — больше 36 кадров на лист не брать). Расшифровка: панель engagement-panel-searchable-transcript → EXPANDED. Сначала дождаться/пропустить рекламу (`.ad-showing`).
- [замена героя] Чтобы поменять героя в готовом ролике без перерендера: plate без героя (`NOHERO=1`), разница кадров draft vs plate даёт маску и прозрачность старого героя → новый спрайт на то же место (`swap_hero2.py`).
- [ходьба] Ходьба на месте читается как движение, если под ней панорамировать фон (bgpan); идти по кадру — vx, в обратную сторону — flip.
- [беговая дорожка] Персонаж на дорожке: проп под углом, ступни на ленту по расчёту поворота; персонаж sc 0.85, иначе руки (rails) не достают до поручня.
- [листы без сетки] Лист «ползёт» модель разложила не 4×2, а рядами по 2–3 — нарезка по компонентам, склеенные фигуры выбрасывать.
- [память] Во время полного рендера (Pool 2) не запускать другие процессы с загрузкой спрайтов — OOM-kill.
- [синхронизация] Короткие подсцены внутри одной фразы ставить по позиции слова во фразе, иначе sync_text перетаскивает плашки и они наезжают друг на друга.

## Правки автора по пакету 05–09 (2026-11-26, вечер)
- [камера/крупность] Фон каждой сцены раньше бесконечно «наезжал» (через 10 с ~120%) и на следующей сцене одним кадром прыгал на 100%. Теперь: наезд фона +4% за 6 с и дальше держится; соседние `loc()` с тем же фоном склеиваются в один план (без шторки и без сброса). Правило: смена крупности одним кадром допустима только при настоящей смене плана (новая локация / общий ↔ портрет). Иначе — либо держать крупность, либо плавный быстрый отъезд (`cam(..., eout=0.4–0.6)`).
- [отжимания] В листе `pushup` ячейки 4–6 смотрят в другую сторону (и в 4 — два тела). Анимация «отжимается на 2 стороны». Цикл фаз задаётся `CYCLE` в render_b5: pushup=[0,1,2,3,3,2,1,0]. Перед использованием любого листа смотреть, в одну ли сторону смотрят все 8 фаз.
- [отжимания от скамьи] Модель рисует скамью разной и «плавающей». Собираем программно: `spr/inclineB` = кадры pushup 0–3, повернутые на 17° вокруг ступней + одна нарисованная скамья под руками (статична во всех кадрах).
- [bird dog] Первый лист смешал профиль и анфас («повороты влево-вправо»). Перегенерирован с «STRICT SIDE PROFILE VIEW: ALL EIGHT figures face the SAME direction, head on the RIGHT». Это добавлять в промпт каждого горизонтального упражнения.
- [нарезка] Широкие позы (wifi, jumping jacks) вылезают за ячейку сетки → обрезанные локти и куски соседа. Проверять каждый кадр: альфа касается края кадра или есть лишние компоненты → резать `compcut.py`. Предметы (МРТ, луна) — тоже `compcut.py`, не сеткой.
- [кошелёк] Зелёные купюры вырезались хромакеем. Для предметов с зелёным цветом: ключ только по яркому #00FF00, связанному с краем кадра (см. props5/f6).
- [кровать] Лежащий спрайт на боковой кровати выглядит «поперёк». Сцены пробуждения — стоя в спальне (лист morning).
- [проверка] `lint_img.py` — предметы, вылезающие за кадр.
