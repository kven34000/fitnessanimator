# Разбор ролика «50 приседаний каждый день» + первая red-neon версия

## Исходник (русский канал)
- 1280×720, 60 fps, 2:31. Плоский светло-серый фон, мускулистый «маскот» без лица, ~30 статичных поз.
- Смена позы на каждую фразу (1,5–4 с), pop-появления, приседание из 3–4 спрайтов по кругу.
- Подсветка мышц цветными заливками по словам; иконки в кружках; плашки-«кнопки»; заголовки-печатная машинка; красный крест кистью; onion-skin в финале.
- Субтитры 2–4 слова, белые с чёрной обводкой. ~130 слов/мин, хук в первые 3 с, «досмотри до конца» на 8-й секунде, структура «неделя 1/2/3 → месяц → честно → бонус → CTA».
- Голос доминирует, музыка тихая, короткие SFX на поп-апах.

## Red-neon версия (2026-11-19)
- Персонаж: аниме-парень, чёрно-красные волосы, тех-маска. 14 поз из одного листа (Nano Banana 2.1, 4K).
- Тёмный фон, красное свечение, неоновая сетка-пол, частицы, караоке-субтитры, неоновые плашки, глитч-заголовки «НЕДЕЛЯ N», тряска камеры, phonk-бит 140 BPM.
- RU-голос: ElevenLabs v4, Mikhail Orlov. EN-версия: Alistair Ashford (1472).
- 1920×1080, 30 fps, −14 LUFS. Код: engine/render.py, audio.py, words.py, poses/.
