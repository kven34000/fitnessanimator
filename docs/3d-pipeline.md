# 3D-пайплайн канала (эксперимент 2026-11-19, отложен — канал перешёл на 2D)

## Требования к роликам (от автора канала)
- Персонаж без одежды, только плавки/шорты; мышцы крупные, анатомически правильные.
- Каждая названная мышца подсвечивается на теле ровно на этом слове — только сама мышца по её форме.
- Подсветка зелёная, чёткая, светится сама мышца.
- Всё, что упоминается, визуализируется. Никаких статичных картинок.
- Движения естественные: процедурные позы и CMU-мокап забракованы, используем Mixamo.
- Контуры аккуратные и тонкие. Шорты объёмные. Стиль red-neon, аниме, молодёжный.

## Модель — бесплатная база MakeHuman
- Модель Tripo (775 кредитов) забракована автором как слабая.
- Тело: MakeHuman через аддон MPFB2 (GitHub makehumancommunity/mpfb2, CC0), мужчина, мускулатура на максимум + локальные таргеты; риг mixamo из MPFB.
- Рельеф: `archive_3d/mhs/sculpt.py` — аниме-рельеф и маски мышц в атрибутах вершин _MA.._MD + линии _INK.
- Голова: волосы, маска и лицо с модели Tripo.
- Сборка: `mk_human.py → stageA.py → testsculpt.py → build_mh.py` (скелет Mixamo из Air Squat.fbx) → mh_<Clip>.glb.

## Движения
- Mixamo (FBX, 30 fps): Air Squat, Idle, Taunt, Mutant Flexing Muscles, Running Up Stairs, Standing Thumbs Up, Pointing Gesture. Скачивание только через браузер автора (Adobe-аккаунт); FBX в git не хранятся.
- Удачные отрезки: Air Squat — цикл 1,87 с; Taunt 1,2–3,0 с; Pointing 0,35–1,2 с; Mutant Flex 1,8–3,2 с.

## Движок
- three.js в headless Chrome: engine3.html (MH-модель), engine2.html (старая Tripo).
- Аниме-шейдинг, тонкий контур, неоновое свечение, сетка-пол, частицы; маски мышц из вершин.
- Итог автора: «в магнифике не получилось», MakeHuman — непропорционально; выбран 2D-пайплайн.
